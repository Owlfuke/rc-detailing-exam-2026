# RC Detailing Field Exam 2026 (Client-Side Standalone)

เว็บแบบทดสอบความรู้หน้างาน `TEST-01 แบบทดสอบความรู้หน้างาน Engineer 2026` ทำงานแบบ **Client-Side Standalone 100%** ไม่ต้องพึ่งพาฐานข้อมูลภายนอก (Zero Database Dependency) ไม่มีวันหมดอายุ พร้อมระบบจับเวลา ตรวจข้อสอบอัตโนมัติ เฉลยละเอียด และ Score Board ประจำเครื่อง

---

## จุดเด่นของระบบ

- **Standalone 100%:** ไม่ต้องสมัครหรือเชื่อมต่อ Supabase / Database ภายนอก หมดปัญหาฐานข้อมูลหลับหรือหมดอายุ
- **โจทย์ 10 ข้อ รวม 30 คะแนน:** รองรับทั้งช่องกรอกตัวเลข (พร้อมปุ่มสลับเครื่องหมาย +/-), ข้อเขียน และตัวเลือก
- **ภาพประกอบสมบูรณ์ 8 รูป:** ครอปจากข้อสอบต้นฉบับตรงตามโจทย์ทุกข้อ
- **ระบบตรวจข้อสอบทันที (Instant Grading):** คำนวณคะแนนตามเกณฑ์ความคลาดเคลื่อนที่ยอมรับได้ ตรวจสอบคำสำคัญในข้อเขียน และสรุปผลเปอร์เซ็นต์ทันทีหลังกดส่ง
- **เฉลยละเอียดและเอกสารอ้างอิง:** แสดงวิธีคิดและมาตรฐานอ้างอิง (ACI, ว.ส.ท., Detailing Manual) ทุกข้อ
- **ปลดล็อกเอกสาร & วิดีโอบรรยาย:** ลิงก์ Google Drive และวิดีโอ YouTube Lecture 1–2 ปลดล็อกให้ศึกษาต่อหลังส่งคำตอบ
- **Score Board & ประวัติการสอบ:** บันทึกประวัติและจัดอันดับผู้สอบในเบราว์เซอร์ผ่าน `localStorage`
- **Responsive Design:** รองรับทั้งโทรศัพท์ แท็บเล็ต และคอมพิวเตอร์

---

## วิธีเปิดใช้งาน

### 1. ทดลองในเครื่อง (Local)
เปิด Terminal ในโฟลเดอร์โปรเจกต์แล้วรัน:
```powershell
python -m http.server 8080
```
จากนั้นเปิดเบราว์เซอร์ไปที่ `http://localhost:8080` (หรือสามารถเปิดไฟล์ `index.html` บนเบราว์เซอร์ได้โดยตรง)

### 2. นำขึ้น Cloudflare Workers / Pages
```powershell
npm run build
npm run deploy
```

### 3. นำขึ้น GitHub Pages
สามารถนำไฟล์ทั้งหมดในโฟลเดอร์หรือใน `dist/` ไปตั้งค่าเปิด GitHub Pages ได้ทันที

---

## โครงสร้างไฟล์สำคัญ

- `index.html` — หน้าเว็บหลักและ Shell ของระบบ
- `app.js` — Client-side Grading Engine, Router, Timer, UI Controller และ LocalStorage Manager
- `config.js` — ตั้งค่าชื่อข้อสอบ เวอร์ชัน เกณฑ์ผ่าน และลิงก์เอกสาร/วิดีโอ
- `styles.css` — ดีไซน์และธีม Responsive UI
- `assets/` — รูปภาพประกอบโจทย์ข้อสอบทั้งหมด
- `scripts/build-public.mjs` — สคริปต์รวมไฟล์ Static ไปยัง `dist/`
